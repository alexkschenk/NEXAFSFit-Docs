Bounds, links, sharing and fit statistics

Four different parameter states¶

State or ruleWhat it does
Free parameter with Min/MaxThe optimiser can choose a value inside hard bounds
Fixed parameterHeld at its value; use the Free checkbox, not equal Min/Max
Expression-linked targetCalculated from other parameters through a supported relationship
Static specificationUsed by the shape but not included as an optimised parameter, such as Lorentzian/Voigt gamma

The initial value seeds an optimisation. It is not a constraint on its final value unless the parameter is fixed or tightly bounded. Set independent limits with the table or μ-bound handles.

For graphical arrangement, dragging an independent peak position translates that peak’s interval while preserving its offsets from μ. The resulting Min/Max remain hard limits during optimisation. Fixed states and parameter links stay enforced, and numerical value edits do not translate limits.

In the GUI, Peak constraints… supports a target equal to a reference plus a fixed or bounded fitted separation. For example, constrain P2 mu relative to P1 mu with a separation between 1.8 and 2.2 eV. The separation has its own value/bounds; the target is derived. Edit the source/separation, rather than the target’s inactive independent bounds. For the dialog sequence, equality examples and removal behaviour, see linking peaks and edges.

Link/Unlink edge to μ… sets any edge’s position relative to a chosen peak. Each edge can have its own exact offset/source. Linked position scope follows the controlling peak in simultaneous fitting; these offsets do not add free parameters. Unlink makes that edge independent again. Relationship cycles and incompatible references are rejected. Loaded model files cannot introduce arbitrary Python or arbitrary expression text for execution.

Sharing across spectra¶

Sharing concerns a simultaneous series fit:

  • global: one parameter value across the chosen spectra.

  • per_spectrum: an independent value for each spectrum.

Independent propagation strategies fit independent parameter sets even if their models contain global sharing labels. A group name such as “surface” does not change this rule. Linked target scopes follow their reference/separation dependencies, so some target Sharing fields are inferred rather than editable.

The GUI’s series introduction explains reference-relative limits and two-pass reseeding. These are separate choices from sharing.

Reference-relative and pass-two windows¶

Reference-relative and pass-two windows restrict allowed parameter intervals. With seed p0p_0p0​, absolute tolerances intersect [p0−b,p0+a][p_0-b,p_0+a][p0​−b,p0​+a] with the existing bounds. Percentage tolerances replace b,ab,ab,a by the entered percentages of ∣p0∣|p_0|∣p0​∣. Mean reseeding is an unweighted arithmetic mean over selected successful fits, not an uncertainty estimate. See the two-pass procedure.

Soft trends and strict constraints¶

A soft trend adds penalty residuals to the data residual vector. Its strength and tolerance control a preference: a finite penalty does not mathematically guarantee monotonicity, a chosen endpoint or a maximum step.

Strict trends impose inequalities/equalities through a constrained optimiser. In this GUI they use an adapter-side SLSQP path; ordinary unconstrained-by-trends fits use the existing least-squares/TRF path. Strict trends are not a new native lineshape or a modification of the measured spectra.

Trend rules couple selected spectra. Scan order or explicit coordinates define their spacing. Nonuniform time/dose coordinates change derivative limits and must be interpreted in the chosen units. An identified maximum/minimum refers to a particular scan, not simply to whichever scan currently has the largest fitted value.

Derivative-limit units¶

For ordered per-scan values pip_ipi​ and strictly increasing coordinates xix_ixi​, the maximum-slope rule uses si=(pi+1−pi)/(xi+1−xi)s_i=(p_{i+1}-p_i)/(x_{i+1}-x_i)si​=(pi+1​−pi​)/(xi+1​−xi​). The maximum-curvature rule uses ci=2(si+1−si)/(xi+2−xi)c_i=2(s_{i+1}-s_i)/(x_{i+2}-x_i)ci​=2(si+1​−si​)/(xi+2​−xi​). Strict rules bound their absolute values; soft versions penalise excess over the chosen nonnegative maximum. With equal-order spacing, the units are parameter/scan and parameter/scan². Changing time/dose units changes numerical derivative limits.

Strict increasing/decreasing and extrema allow ties. A straight-line constraint means zero curvature; constant-value means zero adjacent change. Neither means “small but nonzero”: use explicit derivative maxima for that. Soft log smoothing does not imply log-space strict inequalities; strict trends use linear values.

Read the residual before trusting a number¶

The data residual is measured intensity minus model. Unweighted chi-square is the sum of squared residuals over the selected fit domain. Its numerical scale depends on the intensity units/preparation. A smaller chi-square alone does not prove that a more complex model is scientifically preferable.

Last fit results reports evaluations, chi-square, reduced chi-square and information criteria. Check systematic residual structure, values at bounds, sensitivity to the fit domain and whether parameters are identifiable. The current single-spectrum GUI does not provide a general uncertainty-weight editor.

A reported standard error is a local covariance-based estimate when available. It is not a complete assessment of calibration error, preprocessing choices, model inadequacy or correlated parameters. An unavailable error is blank in CSV, not zero. A bound-hit indicator is a prompt to inspect the chosen limits.

For simultaneous fits, joint statistics describe the entire optimisation; per-scan chi-square and point counts are reported separately. Soft penalty terms can contribute to the joint objective. Do not interpret that total as only a single scan’s spectral misfit.

Strict-trend fits currently have no covariance/stderr estimate. Their reduced chi-square and information criteria are approximate because active inequalities are not subtracted from the degrees of freedom. Only ftol and the evaluation budget apply to this path; xtol/gtol are inactive.

Optimisation controls¶

The default GUI single-spectrum budget is 50,000 residual evaluations, with ftol, xtol and gtol each 1e-8. Finite-difference derivative calculations consume evaluations; the budget is not an iteration counter.

Use Fit settings… to change these values. Tighter tolerances demand more work and do not guarantee a better physical model. A failed optimisation retains the prior successful result. Save a session to retain that result and its settings.
