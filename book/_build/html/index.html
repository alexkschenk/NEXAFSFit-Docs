NEXAFSFit

NEXAFS modelling, preparation and fitting with the graphical interface.

Use the graphical interface to inspect scans, build models and fit spectra. This manual introduces the current workflow using synthetic exercises and a folder-to-results guide, with reference material for interpreting fitted parameters.

Graphical interface

Learn to import spectra, construct models interactively, refine fits and inspect results.

Scientific reference

Explore the meaning of model parameters, lineshapes, constraints and fitting choices.

Worked examples

Follow complete, reproducible analyses with associated datasets.

Version and scope

The manual includes GUI 0.2.28 and the supplied numerical engine. Minor interface refinements may follow. Advanced experimental examples and videos are planned; they are not prerequisites for the basic workflows documented here. Windows executable distribution is also future work.
