Worked examples and introductory data

Choose a known synthetic dataset to practise the GUI. The examples use distributable files and recorded generating truth; they are not experimental component assignments. For your own native acquisitions, the folder-to-results workflow connects the same controls without prescribing an experimental model.

Introductory two-peak dataset¶

A small, reproducible example is supplied for learning the GUI. It contains two Gaussian peaks, a small linear background and seeded random noise. There are no experimental assignments, reference-foil features or raw-monitor channels in these data.

Files¶

All three files are under docs/book/examples/data/ in the source checkout.

FileContents
two-peak-spectrum.csv221 energy/intensity pairs, with one CSV header row
two-peak-model.jsonVersioned starting model that the GUI can open onto the CSV
two-peak-truth.jsonKnown generating values, random seed and noise level

The energy range is 281–292 eV in 0.05 eV steps. Intensity is in arbitrary units. Noise is independent Gaussian noise with standard deviation 0.006 and generator seed 20261123.

QuantityGenerating value
P1 area / mu / sigma1.60 / 285.00 eV / 0.32 eV
P2 area / mu / sigma0.95 / 287.20 eV / 0.55 eV
Background level at the full-grid mean0.04
Background slope0.002 intensity units/eV

The supplied seed deliberately differs from the generating model. Peak areas, positions, widths and background level are free; background slope is fixed. No edge, gain or dE term is needed.

Use the example in the GUI¶

Follow Your first spectrum fit: import the CSV, open the model JSON, fit the full domain and inspect the residual. Save a session and export the fitted curves/parameters.

Things to try¶

  • Move a starting peak slightly, refit and compare the recovered values.

  • Change a bound enough to exclude the true position. Inspect the residual and at-bound indication rather than accepting convergence alone.

  • Fix one Gaussian width, then inspect how that affects area and residuals.

  • Narrow the fitting domain while keeping the full-grid background reference.

  • Compare a saved successful CSV fit report with later edits to the working model.

These exercises change modelling assumptions. They are not evidence that extra components or narrow bounds improve a scientific interpretation.
