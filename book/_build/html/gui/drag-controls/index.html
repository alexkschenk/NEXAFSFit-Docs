Dragging components and setting peak bounds

Implemented controls — GUI 0.2.26

This page describes the actual component handles and their parameter conversions. Dragging edits the working model; it does not run an optimisation. Use Fit spectrum after arranging the components and their allowed ranges.

Select a component and expose its controls¶

On a compact layout, select the Components tab or reopen it from View. Expand Display options below the plot for Focus Mode, fit-window and μ-bound visibility, edge subtraction and component offsets. See layout controls.

  1. Click a peak or edge curve, its component-list entry or its parameter-table header. Clicking a curve selects it; grab a handle to move it.

  2. Keep Lock fit range checked while arranging peaks, so the shaded fitting region does not move accidentally. Show fit window can hide that region.

  3. Leave Focus Mode on to fade unselected components, or turn it off for comparison.

  4. Check Show μ bounds when you want to edit the selected peak’s position limits.

The curve must be visible in the component list for its handles to appear. The handle colours below identify controls; component line colours can be changed independently. Edges have their own drag controls; the linear background is edited in the parameter table.

The orange target can move in both directions together. If μ is fixed/linked, only its free area direction can move; if A is fixed/linked, only its free position direction can move. Dragging the curve body is not a substitute for the target.

Move position or change height¶

Drag the orange target horizontally to translate the peak, vertically to alter its contribution, or diagonally to do both. It belongs to the individual component, not the total envelope or data-plus-edge height. A is integrated area, so the GUI converts the target height using the actual profile, gain and optional component scale. It does not simply write the height into the A cell.

Use the blue line to change μ alone. For Gaussian, Lorentzian and Voigt peaks, the maximum is at the displayed μ. For an EMG, the orange maximum is generally to the right of its blue μ line. Moving the orange target preserves that shape offset; it does not redefine EMG μ to be the maximum.

Position drags carry the μ interval¶

While dragging the blue μ line or the position direction of the orange target, the original Min/Max limits do not clamp the movement. They translate with μ, preserving their original, possibly asymmetric distances. Bound lines temporarily hide during the gesture and return on release if Show μ bounds is enabled. For example, μ = 285.00 with Min = 284.80 and Max = 285.50 becomes μ = 288.00, Min = 287.80 and Max = 288.50 after dragging. Infinite endpoints stay infinite.

Fixed positions remain fixed. Linked positions still follow their source/separation; dragging a source peak moves its linked peaks and linked edges without changing those relationships. This shortcut does not disable links or change the fit domain. The translated interval is the hard interval used by the next fit. Table value edits retain existing bounds; dragging a μ-bound line edits the interval without moving μ. A completed position drag, including its new limits, is one Undo step.

A double-left-click inside the main data axes adds a new peak at that energy, using the shape selected in Component controls. Its height is estimated from the data above the current continuum; existing peaks stay in place. Use the orange target or blue line to move an existing peak. The Add multiple peaks dialog uses its own double-clicks to stage candidates for later addition; see batch creation.

Change width without changing maximum height¶

Grab either green arrow endpoint. Moving it farther from the centre broadens the component; moving it inward narrows it. Both sides update symmetrically.

  • Gaussian and EMG: the parameter is sigma.

  • Voigt: the parameter is its Gaussian sigma; gamma stays a separate table setting.

  • Lorentzian: the parameter is its static gamma, which can be edited graphically but is not an optimiser variable and has no Free checkbox.

The label reports one sigma or gamma on each side, matching its numerical parameter. The full arrow span is twice that radius. These handles do not claim to measure the total FWHM of every lineshape.

The drag adjusts A to keep the component’s maximum height constant. A broader peak therefore usually acquires more integrated area. Editing sigma/gamma directly in the table instead changes only that value and can change height at constant A. Width dragging requires a free, independent A and, for sigma, a free independent width. If the required A falls outside its bounds, the height-preserving change is rejected; inspect Messages rather than assuming the width control is broken.

Change EMG asymmetry¶

The purple horizontal tail arrow appears only for EMG peaks. Its origin is the displayed μ and its length is tau. Drag its right endpoint outward for a longer high-energy tail, or inward for a shorter tail; tau = 0 is the Gaussian limit used by the engine. The origin is not a second free drag endpoint.

μ and sigma stay unchanged while A adjusts to preserve maximum height. The maximum can shift horizontally as the asymmetry changes, so the orange target can move even though the blue μ line stays still. Tau must be free/independent, A must be free/independent, and both sets of bounds apply. This arrow is a parameter control, not a measured width or a peak-to-peak separation.

Drag ionisation-edge parameters¶

Select a visible edge in the component list or click its curve. The same controls work for the first edge and each additional edge; only the selected edge is edited.

Edge controlDrag directionParameter change
Blue vertical position lineLeft/rightE_edge within its existing bounds
Orange Move edge / step target at the edge midpointLeft/right and/or up/downE_edge and/or edge_step; fixed or linked axes stay locked
Green width-arrow endpointToward/away from the centrew_edge, with the edge_step parameter unchanged
Purple post-edge diamondUp/downpost_slope at the indicated post-edge energy; horizontal motion is ignored

The orange target belongs to that edge alone, excluding peaks, the linear background and other edges. It lies at the transition midpoint, not the final step level. Its height is converted using the native edge response and gain; edge_step is a step amplitude, not integrated peak area A. The width arrow shows w_edge on each side; it is not an EMG tail or a peak-position bound.

Added post_slope starts fixed at zero. Enable its Free checkbox before dragging the purple diamond. Other fixed/linked parameters likewise retain their state: a peak-linked E_edge cannot move independently, but its free step, width or slope can still be edited. Edge parameter bounds continue to clamp edge drags; the travelling-interval behaviour above applies to peak μ only. With zero gain the height/slope response cannot be inverted, so those controls are unavailable.

These controls follow Offset components, with the visual shift removed during height conversion. They hide when Subtract current edges is checked or that edge’s visibility is off. Turn subtraction off to edit an edge visually. Plot curves update live, the table refreshes on release, and each completed drag has one Undo step.

Set position bounds by dragging lines¶

  1. Select the peak and enable Show μ bounds.

  2. Find the vertical lines labelled with that peak’s μ min and μ max. Their labels distinguish them from the blue current-position line.

  3. Drag μ min to set the lowest permitted position and μ max to set the highest.

  4. Release and check that peak’s Min/Max cells in the parameter table.

For example, a Gaussian currently at μ = 285.00 eV can have Min = 284.80 and Max = 285.20 eV. Moving either bound changes the allowed interval; it does not move the current peak to that endpoint or start a fit.

A limit stops at the current μ if dragged across it; the two bounds cannot collapse to the same value. A fixed peak can still have its bounds edited, but remains fixed until Free is enabled. Its A, fixed/free state and Sharing are unchanged by a bound drag. Use exact numerical Min/Max edits when you need a precise final value.

If a bound is infinite or outside the view¶

Zoom to the desired allowed interval, keeping the blue μ line inside it. Right-click the main plot and select μ bounds from zoom. This sets both position limits from the visible energy interval, switches their display on and slightly widens the view so both lines are accessible. Then refine them by dragging or table editing. The command is in the plot context menu, not a separate button.

Merely zooming or selecting a peak never changes bounds. If the selected interval excludes the current μ, the command reports the problem and leaves bounds unchanged.

Energy offsets, EMG positions and linked peaks¶

The table/labels report native μ bounds. Their lines are drawn at bound − dE to match the model’s energy convention; with dE = +0.20 eV, a lower μ bound of 284.80 eV appears at plot energy 284.60 eV. For EMG these constrain μ, not its observed maximum. See energy conventions.

A linked μ has no independent bound lines. Change the reference peak’s bounds or the separation parameter in Peak constraints…, rather than trying to drag the linked target. See relative peak constraints.

Three different ranges¶

RangeHow to change itEffect
Visible plot rangeWheel, axis zoom or panChanges what you can see
Fitting energy rangeFitting box or unlocked shaded regionChooses data points used by the optimiser

The μ bounds from zoom command deliberately transfers a viewing interval to parameter bounds; ordinary zoom does not. Lock fit range locks the shaded domain, not peak positions or their bounds. For fit-domain details, see running a fit.

Offsets, feedback and controls that will not move¶

Offset components shifts peaks, edges/background and their handles together. Continue grabbing the shifted handles: the GUI removes the visual offset before converting height to A. Data, envelope and residual are not shifted. Edge-subtracted views likewise do not alter the underlying fit or the parameter conventions. For the full effect on each curve and the offset-factor calculation, see component display settings.

The plot updates during a gesture; the parameter table refreshes on release. Dragging a bound line avoids recalculating unchanged spectra. Each completed drag is one model Undo step (Ctrl+Z). Check Messages for clamping or rejected changes.

Graphical arrangement supplies starting values and allowed intervals. Review them numerically, then fit and inspect the residual; a visually plausible arrangement does not establish a unique or physically appropriate decomposition.
